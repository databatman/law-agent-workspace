# 法考整体框架

> 国家统一法律职业资格考试（法考）总览。

## 一、考试结构

| 阶段 | 内容 | 分值 | 合格线 |
|------|------|------|--------|
| 客观题 | 试卷一 + 试卷二（各100题/150分） | 300分 | 180分 |
| 主观题 | 案例分析、法律文书、论述题 | 180分 | 108分 |

## 二、科目分布

**试卷一**（公法）：法治思想、法理学、宪法、中国法律史、司法制度和法律职业道德、**刑法**、**刑事诉讼法**、**行政法与行政诉讼法**

**试卷二**（私法）：**民法**、**商法**、**民事诉讼法（含仲裁）**、经济法、知识产权法、国际法、国际私法、国际经济法

## 三、分值梯队（客观题参考）

| 梯队 | 科目 | 参考分值 | 说明 |
|------|------|---------|------|
| 第一梯队 | 理论法（含法治思想/法理学/宪法等） | ≈50分 | 分值最高 |
| 第一梯队 | 民法 | ≈50分 | 含民诉相关联动 |
| 第一梯队 | 商经知 | ≈50分 | 商法+经济法+知产 |
| 第二梯队 | 刑法 | ≈38分 | |
| 第二梯队 | 刑事诉讼法 | ≈32分 | |
| 第二梯队 | 民事诉讼法 | ≈28分 | |
| 第二梯队 | 行政法 | ≈28分 | |
| 第三梯队 | 三国法 | ≈15分 | 性价比高、易拿分 |

> 六大核心科目（民法、刑法、刑诉、民诉、行政法、商法）合计占客观题约 **70%** 分值。

## 四、备考策略要点

1. **重者恒重**：高频考点反复出现（如民法合同效力、刑法正当防卫、民诉管辖），优先掌握。
2. **新法必考**：近年重要新法——《民法典》配套解释、《刑法修正案（十二）》（2024.3.1施行）、新《公司法》（2024.7.1施行）、新《行政复议法》（2024.1.1施行）等。
3. **主客一体**：客观题是主观题的基础，案例分析能力要提前培养。
4. **刷题+复盘**：历年真题+每日十题练习，错题回归知识点。

## 五、学习顺序建议

刑法/民法 → 商法 → 行政法 → 刑诉 → 民诉 → 经知 → 理论法 → 三国法
（先实体法后程序法，先大分值后小分值）
