# 公司法 — 公司设立与资本制度

> 法条依据：新《公司法》（2024.7.1施行）第 47、52、54 条 ｜ 考频：★★★

## 一、公司设立

### 1. 设立与成立
- **设立**：为成立公司而进行的筹备行为；**成立**：设立登记完成、营业执照签发之日
- 注意区分：公司权利能力始于设立登记（营业执照签发之日）

### 2. 设立的一般条件
名称、住所（生产经营场所）、章程、符合法定人数的发起人、资本（出资）、法定代表人等。

### 3. 发起人
- 有限公司发起人（设立时股东）：**1 人以上 50 人以下**
- 股份公司发起人：**1 人以上 200 人以下**，且须有过半数发起人在中国境内有住所

### 4. 发起人责任与公司责任 ★
| 情形 | 责任 |
|------|------|
| 设立中 | 发起人为设立公司从事民事活动，公司未成立时由发起人承担 |
| 成立后 | 公司成立并追认的，由公司承担 |
| 出资瑕疵 | 其他发起人与瑕疵出资股东承担连带责任（可追偿） |

## 二、出资制度

### 1. 出资形式
- **货币出资**：原则上以人民币为主
- **非货币财产出资**：实物、知识产权、股权、债权、土地使用权等（可评估作价、可转让）
- **禁止出资形式**：劳务、信用、自然人姓名/商誉、特许经营权、设定担保的财产

### 2. 出资方式（资本制度）
- **无最低注册资本**（除法律行政规定另有特殊要求，如募集设立股份公司）
- **出资期限**：有限公司全体股东认缴的出资额由章程规定，**自公司成立之日起 5 年内缴足**（新公司法限期实缴制）
- **验资**：一般不要求；但募集设立股份公司、特殊行业除外
- **概念辨析**：注册资本（认缴总额）、实收资本（实际缴付）、资产总额（全部资产）

### 3. 出资加速到期 ★★★（《公司法》第54条）
- 公司**不能清偿到期债务**的，公司或已到期债权的债权人有权要求**已认缴出资但未届出资期限**的股东**提前缴纳出资**
- 突破"期限利益"保护，是新法保护债权人的重要机制

### 4. 出资责任 ★★★
**（1）对内责任**：股东未按期足额出资，应对公司**补足出资**；其他发起人与该股东承担**连带责任**（设立时），承担后可追偿。

**（2）对外责任**（对债权人）：未出资/抽逃出资本息范围内，对公司债务不能清偿部分承担**补充赔偿责任**
- 有限性：以**未出资/抽逃出资的本息**范围为限
- 一次性：赔偿总额达到责任限额即免，其他债权人不得再以相同事由请求
- 补充性：公司先清偿，不能清偿部分才请求股东

**（3）与外责任的区分（与法人人格否认对比）**
| 对比 | 出资责任 | 人格否认责任 |
|------|---------|-------------|
| 原因 | 未足额出资/抽逃出资 | 滥用法人独立地位损害债权人 |
| 方式 | 补充赔偿 | 连带责任 |
| 范围 | 有限责任（本息为限） | 可能超过出资范围 |
| 次数 | 一次性 | 可能多次适用 |

### 5. 股东失权制度 ★★★（《公司法》第52条）
- 股东未按期足额缴纳出资，公司发出**催缴通知**（载明不少于 60 日宽限期），宽限期届满仍未缴纳的，公司经**董事会决议**可发出**失权通知**
- 自失权通知**发出之日**，该股东**丧失未缴纳出资的股权**
- 失权股权应依法经**转让或减资注销**（6个月内办理）

## 三、出资瑕疵的影响

1. **权利限制**：有限责任股东未按期足额缴纳出资，公司可根据章程或股东会决议对其利润分配权、新股优先认购权、剩余财产分配权等作出合理限制
2. **诉讼时效抗辩无效**：股东未出资，公司或债权人主张权利的，股东不得以诉讼时效已过抗辩
3. **举证责任分配**：主张抽逃出资的债权人就抽逃出资事实承担举证责任；但被告股东主张出资到位的，承担相应举证责任（依规定）

## 易错点

- **禁止出资**的是劳务、信用、姓名/商誉、特许经营权、担保财产；**可以**是股权、债权、知识产权
- 加速到期以**公司不能清偿到期债务**为条件
- 失权通知**送达/发出之日**生效（董事会决议+催缴+60日宽限期）
- 出资外责任是**补充责任**（先公司后股东），人格否认是**连带责任**

## 真题提示

主观题高频：出资瑕疵时对公司/债权人的责任、发起人连带、加速到期（新法）、股东失权程序。常与法人人格否认对比命题。
