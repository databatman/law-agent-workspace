# 公司法 — 股东权利、资格与公司治理

> 法条依据：新《公司法》第 84、88、89、180-192 条 ｜ 考频：★★★

## 一、股东资格的证明
1. **出资证明书**：签发给股东的书面凭证（有限公司）
2. **股东名册**：记载于股东名册的股东，可依名册主张股东权利；股权转让后受让人记载于名册即取得股权
3. **工商登记**：公司应将股东姓名/名称及出资额向登记机关登记；**未经登记不得对抗善意相对人**（公示效力）

### 股权转让的节点与效力
```
签订转让协议 → 支付转让款 → 股东名册变更 → 登记变更
（负担行为，不动股权）（买方履行）  （买方取得股东权利）（对抗善意相对人）
```

## 二、实际出资人与名义股东 ★★★（股权代持）
实际出资人（实际股东）与实际股东记载不一致（名义股东/代持人）。

**（1）内部关系**：实际出资人与名义股东依**代持协议**（合同）处理，投资权益归实际出资人，名义股东不得擅自行使权利。
**（2）外部关系（对第三人）**：名义股东是登记记载的股东，对外承担股东责任；名义股东处分登记在其名义下的股权，构成**有权处分/善意取得**，实际出资人不得对抗善意受让人。
**（3）出资瑕疵责任**：公司债权人请求未履行出资义务的股东在未出资范围内担责时，名义股东抗辩自己是代持的，法院**不予支持**（先由名义股东担责，可向实际出资人追偿）。
**（4）显名**：实际出资人请求公司承认其为股东、记载于名册的，需经**其他股东过半数同意**（或证明自己实际出资并行使股东权利）。

## 三、冒名股东
被冒名登记为股东者，因本人不知情、未行使权利，**不承担股东责任**（与代持区分：代持系自愿）。

## 四、关联关系与关联交易
- 关联关系：公司控股股东、实控人、董监高与其直接/间接控制的企业之间的关系，及可能导致公司利益转移的其他关系
- **禁止利用关联关系损害公司利益**；造成损失的应承担赔偿责任（关联交易须符合章程/决议，程序正当）

## 五、董事、监事、高级管理人员（董监高）

### 1. 消极任职资格（不得担任董监高的情形）
- 无民事行为能力或限制民事行为能力
- 因贪污贿赂等被判处刑罚，执行期未满 **5 年**
- 担任破产清算公司负责人且负有个人责任，自破产完结未满 3 年
- 担任吊销营业执照/责令关闭公司负责人且负有个人责任，未满 3 年
- 个人所负**较大数额债务到期未清偿**（个人债务违约）

### 2. 董监高的义务
- **忠实义务**：不得利用职权谋取公司商业机会、不得侵占挪用公司资金、不得收受贿赂、不得擅自披露公司秘密
- **勤勉义务**：履行职务应尽管理者应有的注意义务

### 3. 董监高的禁止行为
侵占挪用公司资金、私人账户存储公司资金、贿赂收受非法收入、接受佣金归己、擅自披露秘密、其他违反忠实义务行为。

### 4. 自我交易
- **范围**：董监高本人及其近亲属、其控制的法人/组织，与公司订立合同或交易，均属自我交易
- **规制**：须**经股东会或董事会决议**（关联董事回避）并向公司报告；程序正当+对价公允则有效

### 5. 商业机会与竞业限制
- 不得利用职务便利，为自己或他人谋取属于公司的**商业机会**（经决议同意除外）
- 未经决议同意，**不得自营或为他人经营与公司同类的业务**（竞业限制）

### 6. 关联董事回避
董事会作出决议时，关联董事**不得参与表决**（表决权不计入），其他董事过半数通过。

### 7. 归入权
董监高违反规定获取的违法收入/应由公司所有的收入，公司可行使**归入权**（收归公司）。

### 8. 股东代表诉讼 ★★★（股东为公司利益起诉董监高）
| 要件 | 内容 |
|------|------|
| 主体 | 有限公司：股东（无持股限制）；股份公司：**连续180日以上单独或合计持股1%以上** |
| 对象 | 董监高侵害公司合法权益、股东会/董事会怠于起诉 |
| 前 | 股东书面请求监事会（或监事）/董事会（或董事）起诉，被拒绝或 30 日内未起诉 |
| 前置程序豁免 | **情况紧急、不立即起诉将使公司利益受难以弥补损害**的可直接起诉 |
| 结果 | 诉权利益归属公司（胜诉利益归公司），费用由公司承担（合理部分） |

### 9. 股东直接诉讼
董监高直接侵害**股东个人权利**（如侵害知情权、利润分配权），股东以自己名义直接起诉。

### 10. 影子董事、高管（《公司法》第192条）
实际执行公司事务的控股股东/实控人（非登记董监高），在特定情形下参照董监高义务承担相应责任（"影子董事"）。

## 易错点
- 股权代持中，**对外以名义股东为准**（出资瑕疵先由名义股东担责，可追偿）
- 名义股东处分登记其名下股权→善意取得，实际出资人只能向名义股东主张
- 股东代表诉讼：股份公司须**180日+1%**；前置程序可因情况紧急豁免
- 竞业限制、商业机会均须**经决议同意**方可豁免
