# 商法 — 核心考点总览

> 来源：《2026 法考·刘安琪商法应试薄讲义（主客一体）》整理 ｜ 分值：商法系法考重大分值板块（商经知合计≈50分）

## 知识体系（七大编 + 信托法）

```
商法
├── 公司法            基础理论/能力/设立/股东权利/治理/财务/重大变更/解散清算/两类公司
├── 合伙企业法        普通合伙企业、有限合伙企业、解散清算
├── 个人独资企业与外商投资法
├── 证券法            发行/交易/收购/信息披露/投资者保护（+证券投资基金法）
├── 保险法            基本原则/保险合同/人身保险/财产保险
├── 破产法            基本制度/债权申报/债务人财产/破产程序（重整/和解/清算）
├── 票据法            票据特征/汇票/本票支票/票据权利与抗辩
└── 信托法            信托设立/信托财产独立性/三方当事人权利/信托终止
```

## 核心高频考点（★★★）

| 板块 | ★★★ 高频考点 | 关键法条 |
|------|-------------|---------|
| 公司法 | 公司法人人格否认（纵/横向）、公司担保与越权担保、加速到期、股东失权、名义股东与实际出资人、股东代表诉讼、收益分配、减资、司法解散、对外股权转让与优先购买权、股权回购、决议效力 | 《公司法》23/89/192条 |
| 合伙企业法 | 普通合伙债务清偿（双重优先）、有限合伙表见普通合伙 | 《合伙企业法》38-42条 |
| 证券法 | 信息公开不实责任 | 《证券法》85条 |
| 保险法 | 投保人如实告知、人身保险投保、受益人认定、财产保险代位求偿 | 《保险法》16/60条 |
| 破产法 | 破产费用、共益债务、重大财产处分、别除权/撤销权/取回权/抵销权、清偿顺序 | 《企业破产法》41-43/69条 |
| 票据法 | 票据效力、票据抗辩与抗辩切断、对价 | 《票据法》13条 |
| 信托法 | 信托财产独立性 | 《信托法》15-17条 |

## 题型与命题特点

1. **主客一体**：商法主观题常以"案例+法条"形式考公司治理、股权、破产清偿（如"出资责任"案例题），客观题考概念辨析与程序节点。
2. **商诉结合**：商法与民诉联动（如分公司诉讼地位、破产对诉讼的影响、代表诉讼程序），复习时需与民诉衔接。
3. **新法必考**：新《公司法》（2024.7.1施行）是命题重点——5年实缴、审计委员会替代监事会、横向人格否认、董事忠实勤勉义务细化等。
4. **法条原文**：商法题目常直接考查法条（尤其公司设立、出资责任、破产清偿顺序、票据效力），需熟记关键条文。

## 备考提示

- 公司法占商法比重最高，优先掌握；「人格否认、担保、出资责任、股权转让、决议效力」为绝对高频
- 合伙企业法与有限公司对比记忆；破产法抓住"清算/重整/和解"三分支与清偿顺序主线
- 证券法重「信息公开不实、内幕交易、操纵市场」等禁止性规范；票据法重「无因性、抗辩切断、对价」
- 使用「考频标注」：★★★必掌握（主+客），★★重点，★一般，无标占了解
