# 公司法 — 财务、重大变更与解散清算

> 法条依据：新《公司法》第 210、211、213-225、229-238 条 ｜ 考频：★★★

## 一、收益分配制度 ★★★
**（1）前提**：公司有可分配利润且已弥补亏损、提取公积金。
**（2）分配顺序**：
```
弥补亏损 → 提取法定公积金（税后利润10%，累计达注册资本50%可停） → 提取任意公积金（章程/股东会可决议） → 向股东分配
```
**（3）分配规则**：有限公司按**实缴出资比例**，全体股东另有约定除外；股份公司按**持股比例**（章程另有规定除外）。
**（4）违法分配的后果**：违法分配利润的，股东应退还；给公司造成损失的，股东及负有责任的董监高承担赔偿责任。
**（5）分配时间**：经股东会/董事会决议后，在法定期限内分配（弥补亏损、提取公积金后的利润）。

## 二、公司重大变更

### 1. 增资（增加注册资本）
- 决议程序、增资期限、**优先认缴权/优先认购权 ★**（——现有股东在同等条件下优先认缴）
- **对赌协议【主观链接】**：投资方与目标公司/股东的对赌安排效力（与"资本维持、股东抽回出资"的边界判断）

### 2. 减资（减少注册资本）★★★
- **决议程序**：股东会特别决议（2/3以上表决权）
- **债权人保护**（不适用"简易减资"）：减资应编制资产负债表及财产清单，通知债权人并公告，债权人有权要求清偿或提供担保
- **两种模式 ★★★**：**等比例减资**（按出资比例同比减少，原则）vs **非等比例减资**（须全体股东一致同意或章程另有规定）
- **三个路径（理解）**：减资实际有减少出资金额、减少资本而无返还、弥补亏损等
- **简易减资**：通过减资**弥补亏损**（不涉及向股东返还，不适用债权人保护程序，但不得分配利润、不得免除股东出资义务）
- **违法减资**：股东应当退还/补足，给公司造成损失的由股东和负有责任的董监高承担赔偿责任
- 减资后应办理**变更登记**

### 3. 合并
- **形式**：吸收合并（A+B=A）、新设合并（A+B=C）
- **决策**：股东会特别决议；**简易合并**（公司与其持股90%以上/合并其控股子公司，可简化程序）
- **债权债务承担**：合并各方的债权债务由**合并后存续/新设公司承继**
- **异议股东回购请求权**：对股东会合并决议投反对票的股东，可请求公司按合理价格收购其股权

### 4. 分立
- **形式**：新设分立、派生分立
- **债务承担**：公司分立前的债务由**分立后的公司承担连带责任**（与债权人另有约定除外）
- **异议股东回购请求权**：同合并

### 5. 变更公司形式
- 有限公司变更为股份公司（或反向），须经股东会特别决议；变更前的债权债务由变更后的公司承继

## 三、公司的解散、清算

### 1. 公司解散事由
- 章程规定的营业期限届满或章程规定的其他解散事由出现
- 股东会决议解散
- 因公司合并或分立需要解散
- 依法被吊销营业执照、责令关闭或被撤销
- **司法解散 ★★★**：法院判决解散

### 2. 司法解散（股东请求法院解散公司）★★★
**要件**：公司**经营管理发生严重困难**（如股东会/董事会失灵、僵局），继续存续会使**股东利益受到重大损失**，且通过**其他途径不能解决**。
**主体**：持有公司**全部股东表决权 10% 以上**的股东可向法院请求解散。
**注意**：司法解散是"公司僵局"救济，与清算不同。

### 3. 清算
- **类别**：自行清算（股东/董事等组织）与 法院指定清算（强制清算，逾期不成立清算组）
- **清算组的职权与责任**：清理公司财产、编制资产负债表、通知公告债权人、处理债权债务、清缴税款、代表公司诉讼等；清算组成员故意或重大过失给公司/债权人造成损失的，承担赔偿责任
- **申报债权**：公告之日起 45 日起至 60 日（具体法定期限内申报）
- **清算中诉讼**：以**清算组**名义代表公司参与诉讼
- **财产分配顺序**：
```
清算费用/职工工资/社保补偿 → 税款 → 公司债务 → 剩余财产按出资比例（股份公司按持股比例）分配
```
- **清算转破产**：清算中发现财产不足以清偿债务的，应依法向法院申请破产
- **简易注销**：满足条件的公司（无债务/未开展经营活动等）可适用简易注销程序，全体股东对债务承担相应责任
- **登记机关依职权注销**：对长期未办注销、失联等企业，登记机关可依职权办理注销（其股东负相应责任）

## 易错点
- 法定公积金提取比例：**10%**，达注册资本 **50%** 可不再提取
- 减资"等比例"是原则，"非等比例"须全体股东一致同意
- 简易减资（弥补亏损）**不适用**债权人保护程序，但不得向股东返还财产
- 分立债务：分立后公司**连带责任**；合并债务：存续/新设公司**承继**
- 司法解散门槛：**10% 表决权 + 经营管理严重困难 + 其他途径不能解决**
