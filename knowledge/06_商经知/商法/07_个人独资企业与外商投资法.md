# 个人独资企业法与外商投资法

> 法条依据：《个人独资企业法》《外商投资法》（2020.1.1施行） ｜ 考频：★

## 一、个人独资企业法

### 1. 概述
- **概念**：依照《个人独资企业法》在中国境内设立，由**一个自然人**投资，财产为投资人个人所有，投资人以**其个人财产**对企业债务承担**无限责任**的经营实体
- **特征**：一个自然人出资、无法人资格（无独立法人地位）、投资人承担无限责任、无注册资本要求

### 2. 一人公司与个人独资企业的区别
| 对比 | 一人公司 | 个人独资企业 |
|------|---------|-------------|
| 性质 | 企业法人 | 非法人组织 |
| 出资人 | 股东（法人/自然人） | 一个自然人 |
| 责任 | 股东以出资为限（例外倒置举证） | 投资人无限责任 |
| 注册资本 | 有（认缴制） | 无最低要求 |
| 法律依据 | 《公司法》 | 《个人独资企业法》 |

### 3. 设立
- 投资人为一个自然人、有企业名称、有投资人申报的出资、有固定生产经营场所和必要人员等
- 无最低注册资本要求

### 4. 债务承担
- 投资人以其**个人财产**对企业债务承担**无限责任**
- 企业解散后，原投资人对企业存续期间的债务**仍应承担偿还责任**（债权人5年内未向债务人主张的，除外）
- 投资人申请注销登记前，应当清偿债务或提供担保

### 5. 事务管理
- 投资人可以自行管理企业事务，也可以书面委托/聘用他人管理，受托人/被聘用人在授权范围内行使职权

## 二、外商投资法

### 1. 概述
- **外商投资**：外国投资者在中国境内的投资，包括直接或间接投资新设企业、取得企业股权、投资新建项目等
- **外商投资企业**：全部或部分由外国投资者投资的，依照中国法律在中国境内登记设立的企业

### 2. 外商投资促进制度
- **准入前国民待遇 + 负面清单管理**：国家对负面清单之外的外商投资，给予**国民待遇**（与内资同等）
- 促进措施：提高外商投资便利化、平等适用国家支持政策等

### 3. 外商投资保护制度
- **审慎的外资征收制度**：国家对外商投资不实行征收；特殊情况下根据公共利益需要征收的，应**依照法定程序**进行，并**给予补偿**
- **资金汇入汇出自由化**：外国投资者合法所得可依法自由汇入、汇出（人民币/外汇）
- **强化知识产权保护**：依法保护外国投资者和外商投资企业的知识产权
- **不得减损外商投资企业的合法权益**：国家和地方出台政策不得损害外商投资合法权益

### 4. 外商投资管理制度
- **准入负面清单制度**：对禁止/限制外商投资的领域实行清单管理
- **经营者集中审查**：达到申报标准的，依法进行经营者集中反垄断审查
- **安全审查制度**：对影响或可能影响国家安全的外国投资者投资，依法进行安全审查（审查决定不得复议/诉讼的例外情形）

## 易错点
- 个人独资企业**无法人资格**，投资人承担**无限责任**（区别于一人公司的有限责任+股东有限责任倒置）
- 外商投资征收：**只有公共利益**才可征收，且须**依法定程序+给予补偿**
- 准入前国民待遇是"负面清单之外"才适用

## 真题提示
低中频考点，以概念辨析（一人公司 vs 个人独资企业、外商投资负面清单+国民待遇）为主，识记即可。
