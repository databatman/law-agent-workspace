# 合伙企业法

> 法条依据：《合伙企业法》第 22-24、28、38-45、57-58、70-76 条 ｜ 考频：★★

## 一、普通合伙企业

### 1. 设立条件
- **合伙人**：2 人以上；非完全民事行为能力人、法律法规禁止主体不得作为合伙人
- **书面合伙协议**：依法订立
- **出资**：合伙人可以在合伙协议中约定，可以货币/实物/知识产权/土地使用权等出资（无最低出资要求）
- 名称、生产经营场所

### 2. 合伙企业财产
- 财产性质：各合伙人**共同共有**；合伙存续期间，不得分割、不得擅自处分
- 管理与使用：须经全体/约定程序

### 3. 财产份额的处分
| 行为 | 规则 |
|------|------|
| 对内转让 | 通知其他合伙人（无需同意） |
| 对外转让 | 须**其他合伙人一致同意**；其他合伙人**有优先购买权** |
| 出质 | 须**其他合伙人一致同意**；未经同意出质无效，给善意的第三人造成损失可请求赔偿 |
| 离婚分割 | 共同财产中合伙份额，应依法由合伙人协商/依法处理 |

### 4. 合伙事务执行
- **决议规则**：通常一人一票，**过半数**通过；**一致同意事项**：改变经营范围、处分不动产、转让知识产权、以企业名义为他人提供担保、聘任不属合伙人的经营管理人员、增减注册资本等
- **执行方式**：共同执行 / 委托执行（委托个别合伙人执行）/ 分别执行

### 5. 利润分配与亏损分担
- 顺序：先按合伙协议约定 → 协商 → 实缴出资比例 → 平均（**不得将全部利润分配给部分合伙人，也不得将全部亏损约定由部分合伙人承担**）

### 6. 债务清偿 ★★
- **先企业后个人**：合伙企业债务**优先以合伙企业财产**清偿
- **普通合伙人补充责任**：企业财产不足清偿的，各普通合伙人承担**无限连带责任**（对外），对内按约定/出资比例/平均分担
- **禁止抵销与禁止代位**：合伙人发生与合伙企业无关的债务，相关债权人**不得以其债权抵销**其对合伙企业的债务，**不得代位行使**合伙人在合伙企业中的权利（只能以合伙人个人财产受偿）
- **双重优先原则 ★★**：合伙人的个人债务，**优先以合伙人个人财产**清偿；合伙企业的债务，**优先以合伙企业财产**清偿（两类财产各归其位）

### 7. 入伙与退伙
**入伙**：须经全体合伙人一致同意，订立书面入伙协议；**新合伙人对入伙前债务承担无限连带责任**。

**退伙**：
- **自愿退伙**：协议约定期限但期满退伙/约定事由；未约定期限的，提前**30日**通知退伙
- **当然退伙**：①死亡/被宣告死亡；②丧失民事行为能力；③丧失合伙资格（如被吊销执业资格）；④在合伙企业中的全部财产份额被法院强制执行
- **除名退伙**：①不履行出资义务；②因故意/重大过失给企业造成损失；③执行合伙事务时有不正当行为；④约定的其他事由（须经其他合伙人一致同意，书面通知）

**退伙人对退伙前债务**承担无限连带责任。

### 8. 特殊普通合伙企业 ★★
- 以专业知识提供服务（如律师事务所、会计师事务所）
- **责任划分**（关键）：
  - 合伙人因**故意或重大过失**造成的企业债务：该合伙人承担**无限连带责任**，其他合伙人以其在合伙企业中的**财产份额为限**承担责任
  - 非因故意/重大过失造成的债务：**全体合伙人**承担无限连带责任
- **名称**须注明"特殊普通合伙"；应建立**执业风险基金、办理职业保险**

## 二、有限合伙企业

### 1. 基本结构
- 由**普通合伙人（GP，要承担无限责任、执行事务）+ 有限合伙人（LP，以出资额为限、不执行事务）**组成
- 至少 1 名普通合伙人 + 1 名有限合伙人

### 2. 事务执行
- **普通合伙人执行合伙事务**并对外代表企业；**有限合伙人不得执行合伙事务**（不得对外代表企业）
- **表见普通合伙 ★★**：有限合伙人以合伙的名义行事，第三人**有理由相信其为普通合伙人**并与其交易的，该有限合伙人**对该笔交易承担与普通合伙人相同的无限连带责任**（仅就该笔交易）

### 3. 有限合伙人的特殊权利
- **财产份额转让**：对内转让通知即可；**对外转让**（提前30日通知其他合伙人，不要求一致同意，其他合伙人无优先购买权——区别于普通合伙）
- **出质**：有限合伙人可以将其在有限合伙企业中的财产份额出质（除非合伙协议另有约定，无需一致同意）
- **利润分配**：可以约定将**全部利润分配给部分合伙人**（区别于普通合伙的禁止规则）
- **债务清偿**：有限合伙人以**其认缴的出资额为限**承担责任

### 4. 入伙退伙
- **入伙**：新有限合伙人对入伙前债务，以其**认缴的出资额为限**承担责任
- **退伙**：有限合伙人退伙后，对基于其退伙前原因发生的债务，以**退伙时从企业取回的财产**为限承担责任（区别于普通合伙人退伙的无限连带）

## 三、合伙企业的解散与清算
- **解散事由**：合伙期限届满/全体合伙人一致同意不再经营/约定事由/一名或数名合伙人被除名或退伙而无其他合伙人/依法被吊销执照等
- **清算**：清算人（合伙人担任/指定/申请法院指定）；清偿顺序——清算费用→职工工资社保→税款→企业债务→剩余财产按比例分配
- 清算后企业财产不足以清偿债务，清算人依法清偿，普通合伙人承担无限连带责任（可再追偿）

## 易错点
- 普通合伙**对外转让/出质/一致同意事项**均须**一致同意**；有限合伙**对外转让只需通知**、**出质**无需一致同意
- 普通合伙利润分配**禁止**约定全部给部分人；有限合伙**可以**
- 双重优先原则（企业债务用企业财产、个人债务用个人财产）
- 特殊普通合伙：故意/重大过失→该人无限连带+其他人限（财产份额）；一般债务→全体无限连带
