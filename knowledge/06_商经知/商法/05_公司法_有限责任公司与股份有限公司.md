# 公司法 — 有限责任公司与股份有限公司

> 法条依据：新《公司法》第 84、89、142、144、154、163、227-230 条 ｜ 考频：★★★

## 一、有限责任公司股权转让

### 1. 对外转让 ★★★（《公司法》第84条）
- **通知**：股东向股东以外的人转让股权，应书面通知其他股东
- **优先购买权 ★★★**：其他股东在**同等条件**下有优先购买权；自接到书面通知之日起**30日**内未答复视为放弃
- **变更**：可以**由章程另作规定**（章程优先）
- **注意（新法变化）**：已取消"须经其他股东过半数同意"，仅保留**通知+优先购买权**机制

### 2. 强制执行与继承
- **强制执行**：法院强制执行转让股权时，通知公司及全体股东，其他股东在同等条件有优先购买权（自通知20日内行使）
- **继承**：自然人股东死亡后，其合法继承人可继承股东资格（章程另有规定除外）

### 3. 公司回购股权 ★★★（《公司法》第89条）
- **异议股东回购请求权**：股东对股东会下列决议投反对票，可请求公司按合理价格收购其股权——①公司连续**5年**不向股东分配利润，而公司该5年连续盈利; ②公司合并、分立、转让**主要财产**; ③章程规定的营业期限届满或解散事由出现，股东会决议修改章程使公司存续
- **受压迫股东回购请求权**：公司**控股股东滥用股东权利**，严重损害公司或其他股东利益的，其他股东可请求公司按合理价格收购股权（新法新增）
- 回购股权应在**6个月内**转让或注销（库存股）

### 4. 股权让与担保（"真担保、假让与"）
- 以转让股权形式为债权提供担保：形式上股权转让，实质是担保（按担保处理），到期未清偿则就股权优先受偿

### 5. "一股二卖"
- 股权重复转让的归属：按"登记/记载优先+善意取得"规则处理

## 二、有限责任公司组织机构

### 1. 股东会与董事会职权
- **股东会**：决定经营方针、选举更换董监、审议批准利润分配、修改章程、增减资、合并分立等重大事项
- **董事会**：执行股东会决议、经营管理决策（如制定公司基本制度、聘任经理）
- （股份公司可设**审计委员会**替代监事会）

### 2. 股东会会议
- 定期会议与临时会议
- **表决规则**：修改章程、**增减注册资本**、**合并/分立/解散/变更形式**等须经**2/3以上表决权**特别决议；一般事项经**过半数表决权**通过（章程可约定）
- 召集与主持：董事会召集→董事长/副董事长/代表董事主持→监事会→代表1/10以上表决权股东（按序）

### 3. 一人公司
- 只能设立一个一人有限公司（自然人）
- **组织机构**：股东一人，可设执行董事/监事（可简化）
- **法人人格否认**：一人公司**举证责任倒置**（股东不能证明公司财产独立于个人财产，承担连带责任）
- **担保特殊规则**：为股东/实控人担保同样需股东会决议（关联股东回避）

### 4. 公司决议效力 ★★★（新《公司法》第26-28条）
| 类型 | 情形 |
|------|------|
| **不成立** | ①未召开会议/未进行表决；②出席/表决权不足章程或法定；③同意人数未达通过标准；④其他 |
| **无效** | 决议内容违反法律、行政法规 |
| **可撤销** | ①召集程序/表决方式违反法律/章程 ②内容违反章程 ③决议被恶意侵害股东权益 |
- **决议效力之诉**：股东可提起诉讼；撤销之诉有**60日**除斥期间（自决议作出之日起）
- **影响**：决议被确认无效/撤销/不成立，对依据该决议进行的其他行为（如与第三人交易）的效力，依内外有别处理（善意相对人受保护）

## 三、股份有限公司

### 1. 设立
- **发起设立**：由发起人认购公司应发行的全部股份（发起人1人以上200人以下，过半数在中国境内有住所）
- **募集设立**：发起人认购部分股份，其余向社会公开募集（须经批准）
- 注册资本：为登记机关登记的**已认购股本总额**

### 2. 组织机构
- 股东会（需通知提前时间更长）、董事会（5-19人）、**审计委员会**、监事会
- 上市公司设**独立董事**、**董事会秘书**

### 3. 股份发行（《公司法》第142条）
- **面额股/无面额股**：可择一
- **类别股**：可发行优先股、表决权差异股等（同股不同权，需依法定情形）
- **授权资本制 ★★★**：章程或股东会可授权董事会，在**3年内**决定发行不超过已发行股本**50%**的公司股份（新法引入）

### 4. 股份转让
- 原则：股份可以依法转让（原则上自由）
- **对特定主体限制**：发起人持有的本公司股份，自公司成立之日起**1年内**不得转让；董监高任职期间每年转让不超过其持有股份的**25%**
- **股份回购**：公司不得收购本公司股份（但有法定例外：减少注册资本、与持有本公司股份的其他公司合并、用于员工持股计划、股东对合并分立投反对票时回购等，需依情形定）
- **禁止财务资助 ★★★**：公司不得为他人取得本公司股份提供**财务资助**（借款、担保等），除非经股东会/董事会批准且为员工持股等（避免抽空公司资本）

### 5. 上市公司特殊规则
- 股东会/董事会特殊表决规则、**独立董事**、**审计委员会**、**董事会秘书**
- **关联董事回避**、**股份代持协议无效**（上市公司股权不得代持）、**禁止交叉持股**（公司不得成为自己/控股股东股份的受让主体等）

## 四、国家出资公司（国有独资公司等）
- 由**履行出资人职责的机构**代表国家履行出资人职责
- **国有独资公司**：不设股东会，由**履行出资人职责的机构**行使股东会职权（部分可授权董事会）；设董事会、监事会/审计委员会
- 重大事项（合并分离增减资、发行债券、分配利润等）须报履行出资人职责的机构决定

## 易错点
- 有限公司对外股权转让：**通知+优先购买权**（不再要求过半数同意），章程可优先
- 特别决议需 **2/3 以上表决权**（修改章程/增减资/合并分立解散/变更形式）
- 股份有限公司发起人股份 **1年内** 禁转；董监高每年转让 ≤ **25%**
- 公司不得财务资助他人取得本公司股份（法定例外除外）
- 异议股东回购（89条）：**5年不分红且连年盈利**、合并分立转让主要财产、存续修改章程
