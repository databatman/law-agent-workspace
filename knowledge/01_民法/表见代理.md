# 表见代理

> 法条依据：《民法典》第 172 条

## 概念

行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，**相对人有理由相信行为人有代理权**的，代理行为有效。

## 构成要件

1. **无权代理**：行为人无代理权（自始无代理权/超越代理权/代理权已终止）
2. **权利外观**：存在使相对人相信行为人有代理权的外观（如：
   - 授权委托书过期但未收回
   - 公司印章管理混乱，行为人持有盖有公章的空白合同书
   - 曾为被代理人的代理人，代理关系终止后未通知相对人）
3. **相对人善意且无过失**：相对人不知道也不应当知道无权代理
4. **相对人基于信赖与行为人实施民事法律行为**

## 法律效果

- **代理行为有效**，被代理人承担法律后果（"外表授权理论"）
- 被代理人承担责任后，可向无权代理人**追偿**（内部关系）

## 易错点

| 情形 | 是否构成表见代理 |
|------|----------------|
| 伪造公章 | 一般不构成（相对人未审慎审查） |
| 空白授权委托书（本人出具） | 构成 |
| 代理权终止后未通知相对人 | 构成 |
| 相对人明知无权代理 | 不构成（恶意），为无权代理待追认 |

## 与无权代理（狭义）的区分

- **表见代理**：相对人善意 → 合同有效，无须被代理人追认
- **狭义无权代理**：合同效力待定，被代理人追认才有效；不追认则行为人担责

## 真题提示

常与"合同效力"联合命题：判断代理行为有效后，进一步考查合同对本人与相对人的约束力。
